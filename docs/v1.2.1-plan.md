## 1. Why this is not a flat list of fixes

**A guard hardened over a missing affordance breaks the system.** `AF1` reproduced
the original failure on pristine `bab279e`: freeze materialised `dataset_card.yaml`,
`domains.json`, `manifest.json`, `test.txt` *as the eval set*, `test_item_count: 5`,
exit 0. Its warning: pristine leakage check 2 already returns `False` on this corpus
for a benign reason, so *"a hardened version would refuse every paired-modality
corpus on earth. The guard is not too weak; it is reasoning over a representation
that cannot carry the distinction it needs to make."*

**A state machine over entities that do not exist formalises the wrong things.**
`AF6`: 58 contract models, no `MissionState`, no `RunState`; `stateWrite` is a
merge-patch accepting anything; `readRunState` on a *missing file* returns
`status:"running"` — absence read as liveness.

**~25 enumerated fixes collapse into 7** once one writer owns run state (`AF6 §5`).

Ordering: **structural guards + discovery → domain model → contract → agent
affordances → FSM → remaining governance → knowledge → environment → instrument →
measurement → science.**

## 2. The principle

> Any obligation stated in prose to an agent is an obligation the system has
> decided not to have. **For every invariant, name the writer. If the writer is the
> agent that benefits from violating it, it is not an invariant.** — `AF6 §4`

Move the boundary by **giving the system a writer**, not by adding a matcher. Lane
J: ~15 harms prevented, ~19 backfires, ~64 false positives, and the flagship rule
converted an auditable `Edit` into an obfuscated inode-preserving write.

The pattern exists in this repo, correct, once — `record.ts:162`, *"Absence of a
failure verdict is not evidence of integrity"*, computed server-side. This release
applies it to the other twelve places.

## 3. Cut, and why

- **Inode-aware `stat` on write targets** — guarding harder in the style lane J
  measured net-negative. Custody (2.7) closes the hardlink route with no matcher.
- **Row-by-row retier-doc corrections** → 7.4, delete and generate.
- **Any "add a matcher for X"** — presumed moot until 0.2 lands.
- **Tuning the stop predicate** — cut, not calibrated. `stop.mjs` fails open toward
  stopping and `tree.py:894` toward continuing; you cannot tune your way out of two
  disagreeing defaults.
- Four plugin-root checks → 1.3. Twelve lock retrofits → 1.8. 54 `isError` sites →
  1.7. Two `resolveNodeRef` patches → 1.5.

## 4. Risks

1. **1.10 is the sharpest risk in the release.** A 256 MB one-way migration that
   must adjudicate three live missions. Mitigations: 0.8's **verified** revert point
   first (not merely `git init` — `.gitignore:40` ignores `.evor/runs/`, so the
   naive form protects nothing), dry-run diff reviewed before write, r3 node
   artifacts asserted byte-identical after, and 3.2's schema change folded into the
   same pass so the trees are rewritten once.

   **The alternative was abandonment, and it lost on one fact.** Abandoning the
   three trees removes the input to 9.2 — the re-score of `iir-scan-binnet-02`,
   which the trace README calls the highest-value single action in the whole
   investigation, and which exists under **r3 only**. A node with 12,000 valid
   telemetry records was failed by a directory-naming mismatch; abandoning the
   trees makes that permanent. If 0.8's revert point cannot be established, the
   correct move is to **abandon explicitly and delete 9.2** — not to migrate
   without one.
2. **Phase 2 changes tool contracts the agent files depend on.** Prompts and schemas
   move together or both benchmark arms break.
3. **Phases 0.6 and 2b change agent behaviour**, so nothing measured before them
   compares to anything after. Phase 8 is last for this reason, and v1.2.0's tier
   claims stay unverified until then. Nothing needs retracting — RC7 found the
   numbers *right about a narrower thing than they were quoted for*.
4. **The RED suite is necessary, not sufficient.** Where a phase deletes a call
   site, delete its test deliberately and record why in the phase's commit.
